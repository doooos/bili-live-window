# B站直播原生小窗 · Edge 扩展

把 B 站直播原播放器移到置顶小窗。重点保留直播弹幕及你在播放器中设置的样式。

这是第三方扩展，与哔哩哔哩没有隶属关系。目前通过解压加载安装，未上架 Edge 扩展商店。

## 安装

1. 解压 `bili-live-window-v0.1.0.zip`。
2. 在 Edge 地址栏打开 `edge://extensions`。
3. 打开“开发人员模式”。
4. 点“加载解压缩的扩展”。
5. 选择解压后的 `extension` 文件夹。
6. 刷新已经打开的 B 站直播页。

选择的文件夹内应直接有 `manifest.json`。

## 使用

1. 打开直播间，等画面和弹幕正常出现。
2. 在 B 站播放器中设好弹幕样式。
3. 点网页右下角“直播小窗”。

快捷键为 `Alt+Shift+P`。再次按下可放回网页。

可以拖动、缩放小窗。关闭小窗或点“返回网页”，播放器会回到原位置。请保留原直播标签页，不要关闭或刷新它。

浏览器工具栏中的扩展按钮会提示小窗入口。打开小窗需要你直接点击直播页按钮。

## 弹幕与原播放器

- 使用同一个视频、弹幕层和播放器控件，不重新连接弹幕服务。
- 不重写弹幕字体、字号、颜色、透明度、描边和屏蔽设置。
- 复制页面样式，保留播放器节点及其内部样式。
- 小窗尺寸变化时，B 站可能按自身规则调整字号和弹幕布局。相同设置不代表不同窗口尺寸下的像素完全相同。
- 原播放器内部的控件会一起移动。直播间右侧聊天栏、播放器外的礼物区等不在小窗中。
- 直播没有普通视频的投币和进度条功能；扩展不会添加这些功能。

## 已验证与限制

2026-10-09，在独立 Chromium 146 测试环境完成：

- 真实 B 站直播画面进入小窗，关闭后回到原位置。
- 真实直播弹幕在小窗中持续新增。
- 本地受控页面通过 11 项检查，覆盖原节点保留、样式保留、样式修改、持续播放、暂停状态和反复开关。

尚未在你的 Edge 用户配置中验证全部个人设置。B 站后续修改播放器，也可能影响兼容性。

自动测试中新标签页没有使原页报告“隐藏”，所以尚未证明最小化 Edge 后的长期弹幕刷新。

需要支持 Document Picture-in-Picture 的 Edge。若提示不支持，请更新浏览器。普通视频画中画无法携带网页弹幕层。

小窗仍依赖原标签页。电脑休眠、断网或浏览器丢弃原页面会中断播放。

如果画面或控件异常，先关闭小窗，再刷新原直播页。请等原播放器完整加载后重试。

## 权限与卸载

扩展只在 `https://live.bilibili.com/` 注入。`activeTab` 用于工具栏按钮识别当前直播标签页。

扩展不读取登录凭据，不代发弹幕，不送礼，不接入外部服务器。原 B 站页面仍会正常连接 B 站服务。

在 `edge://extensions` 中停用或删除即可。扩展不更改 B 站账号设置。

## 技术说明

Manifest V3，无构建依赖。使用浏览器的 Document Picture-in-Picture API，将原播放器 DOM 移到新文档，并在关闭时恢复。

API 说明：https://developer.chrome.com/docs/web-platform/document-picture-in-picture

## 开发与测试

扩展本身不需要构建。测试需要 Node.js 18 或更新版本，以及 Playwright 和 Chromium：

```sh
npm install --no-save playwright
npx playwright install chromium
node tools/test.cjs
```

真实直播检查单独运行，会访问所选公开直播间：

```sh
node tools/inspect-live.cjs https://live.bilibili.com/5050
```

测试结果写入 `test-results/`，该目录不提交到仓库。测试使用独立浏览器配置，不使用个人登录信息。

已有工具环境可通过 `PLAYWRIGHT_MODULE_PATH` 指定 Playwright 模块，通过 `BLW_BROWSER_PATH` 指定 Chromium 可执行文件，通过 `BLW_TEST_OUTPUT` 指定结果目录。原始验证使用 Chromium 146；其他版本需重新验证。
